# Handoff de identidad provisional — Sensores Agrícolas

Esta carpeta está lista para compartir con Claude Code. Contiene el brief de marca, guía visual, instrucciones de implementación, un prompt detallado y logotipos SVG editables. El PDF adjunto reúne las 14 pantallas de referencia del prototipo.

## Orden sugerido

1. Comparte esta carpeta completa con Claude Code dentro del contexto del repositorio `IoT_Sensors`.
2. Pídele leer `CLAUDE_CODE_PROMPT.md` y todos los archivos enlazados en este paquete.
3. El prompt exige que primero inspeccione el proyecto y presente un plan con archivos y riesgos. Debe esperar aprobación explícita antes de editar.
4. Tras aprobar el plan, revisa los cambios visuales en escritorio/móvil y en modo claro/oscuro.

## Contenido

- `BRAND_BRIEF.md`: propósito, personalidad, concepto y decisiones provisionales.
- `VISUAL_GUIDELINES.md`: colores, tipografía, contraste y uso del logo.
- `IMPLEMENTATION_INSTRUCTIONS.md`: alcance, límites y criterios de revisión.
- `CLAUDE_CODE_PROMPT.md`: prompt completo listo para pegar.
- `assets/logos/`: lockups e iconos en SVG vectorial editable.
- `assets/references/pantallas-sensores-agricolas.pdf`: contexto visual del prototipo.

## Identidad temporal

**Sensores Agrícolas** es un nombre descriptivo temporal. Nombre, símbolo y sistema visual son una propuesta preliminar para este proyecto; no constituyen una marca registrada ni una decisión comercial definitiva. No iniciar trámites de registro ni sustituir nombres de producto, organización o dominio existentes.
